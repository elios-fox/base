# ClubHub Dark Mode

## Kleurmapping

| Element | Light | Dark |
|---------|-------|------|
| Surface | `#FFFFFF` | `#1C1B1F` |
| Surface Container | `#F5F5F5` | `#2B2930` |
| On Surface | `#1C1B1F` | `#E6E1E5` |
| On Surface Variant | `#757575` | `#CAC4D0` |
| Primary | `#2E7D32` | `#81C784` |
| Primary Container | `#A5D6A7` | `#1B5E20` |
| Secondary | `#F57C00` | `#FFB74D` |
| Tertiary | `#1565C0` | `#64B5F6` |

## Semantic Colors (Dark)
| Status | Light | Dark |
|--------|-------|------|
| Aanwezig | `#4CAF50` | `#81C784` |
| Afwezig | `#F44336` | `#EF9A9A` |
| Onzeker | `#FF9800` | `#FFB74D` |

## Contrast Ratios (WCAG AA)
- Text on Surface: minimum 4.5:1
- Large text on Surface: minimum 3:1
- Icons on Surface: minimum 3:1

Alle bovenstaande combinaties voldoen aan WCAG AA.

## Cards & Elevation
- Dark mode: gebruik tonal elevation (lichtere surface bij hogere elevation)
- Level 0: `#1C1B1F`
- Level 1: `#2B2930`
- Level 2: `#313036`
