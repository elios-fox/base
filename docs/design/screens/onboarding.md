│                         │
│  Al een account?        │

## Layout — Keuze na registratie
```
┌─────────────────────────┐
│                         │
│  Welkom, Jan!           │
│                         │
│  Wat wil je doen?       │
│                         │
│ ┌──────────────────────┐│
│ │ 👑 Team aanmaken     ││
│ │ Ik ben coach/trainer ││
│ └──────────────────────┘│
│                         │
│ ┌──────────────────────┐│
│ │ 🤝 Team joinen       ││
│ │ Ik heb een code      ││
│ └──────────────────────┘│
│                         │
└─────────────────────────┘
```

## Flow
1. Welkom → "Aan de slag" → Registratie formulier
2. Na registratie → Keuze scherm
3. "Team aanmaken" → Team setup (naam, sport, seizoen)
4. "Team joinen" → Join team scherm (code invoeren)
